# Sistema de Busca Inteligente CFTV

Aplicação desktop desenvolvida em Python com Inteligência Artificial para triagem, busca e rastreamento automatizado de alvos em arquivos de vídeo e imagens de CFTV (**NOVACAP**), com suporte a processamento individual e em lote.
